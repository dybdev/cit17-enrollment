# Student Enrollment System

A responsive five-step student enrollment form built with HTML, CSS, and JavaScript for CIT17 Laboratory 1.

## Steps

1. Student ID
2. Name
3. Email
4. Course, BSIT major (when applicable), and year level
5. Review and submit

Open `index.html` in your browser to use the form. No installation or build is required. Required fields and minimum lengths are validated before advancing. Submitted records are displayed below the form for the current session; refreshing clears them. This is a front-end laboratory project and does not send records to a school or database.

## Files

- `index.html`: Accessible form structure and records table
- `style.css`: Responsive layout inspired by the supplied design references
- `script.js`: Step navigation, validation, review, and submission display
